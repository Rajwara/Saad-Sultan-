# Images

Upload your images to this folder using these exact file names. The site picks them up automatically.

| File | Used for |
|---|---|
| `portrait.webp` | Hero portrait. Use a transparent cut-out about 1200px tall. |
| `portfolio/` | Project card images, one per project (see the README in that folder) |
| `testimonial-logos/` | Client logos shown on the testimonial cards (file names are set in `lib/content.js`) |
| `avatar-me.jpg` | Your small avatar next to "Have something in mind?" |
