# Images

Upload your images to this folder using these exact file names. The site picks them up automatically.

| File | Used for |
|---|---|
| `portrait.png` | Hero portrait. Use a transparent PNG cut-out about 1200px tall. |
| `project-01.jpg` … `project-09.jpg` | Project cards (portrait ratio, about 4:5) |
| `avatar-1.jpg` … `avatar-8.jpg` | Testimonial avatars (square) |
| `avatar-me.jpg` | Your small avatar next to "Have something in mind?" |
